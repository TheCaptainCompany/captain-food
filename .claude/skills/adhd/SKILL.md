# `/adhd` — the report is five lines or it is not read

**Shape, in this order, nothing else:**

1. **Now** — one line: what is happening this minute.
2. **Done since last time** — at most three bullets, one line each, no adjectives.
3. **Blocked / red** — one line per item, with the one word that unblocks it (or "nothing").
4. **Needs you** — one line per external item, or "nothing".
5. **Next** — one line.

**Rules.** Max ~80 words total. No headers, no paragraphs, no history, no rationale, no register
trail in the body (the trail line still exists — put it LAST, one line, or link the record). Numbers
only if they change what he does. Names of PRs and issues as links. If detail is wanted, one link
to the status page or the record, never the detail itself. A longer answer is a failure of this
skill, not a feature.

**What it never changes.** The register check runs; the mob runs; records land in full in the repo.
`/adhd` compresses the message to the founder, not the work behind it.
